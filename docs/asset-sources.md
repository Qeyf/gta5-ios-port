# GTA V icon source

The app icon and home-screen logo use the existing Grand Theft Auto V logo,
downloaded on 2026-10-13 from:

- Page: https://brandslogos.com/g/grand-theft-auto-v-logo/
- Original PNG: https://brandslogos.com/wp-content/uploads/images/large/grand-theft-auto-v-logo.png

The source PNG is 1280 × 1124. It is fitted inside the 1024 × 1024 opaque app
icon canvas and resized for the existing HomeIcon image set. The logo lettering
is unchanged. iOS supplies the app icon's rounded mask.
